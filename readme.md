# SRT / SBV 同期歌詞エディタ
v1.0.0準拠(2026年11月10日作成)

## このツールについて
SRT、SBV、TXTファイルとMP3ファイル等を読み込んで、よくある同期歌詞エディタ同様に歌詞の時間指定を行い、出力することができます。

## 使い方
### 〇 時間付きテキストファイルを作成する
1. SRT、SBV、TXTファイルとMP3ファイル等を選択して読み込む。
2. 音楽ファイルを再生しながら「時間を入力」ボタンを押し時間を設定する。

```
※時間指定ボタン押下時のデフォルト選択セルは1行目の開始時間です。入力したいセルを選択することで任意のセルにボタンで時刻を入力することができます。 
 
※終了時間は次の行の開始時間が自動的に入力されます。

※SRTファイルはニコニコ動画、SBVファイルはYouTubeの時間付きテキストフォーマットです。
```

### 〇 SRT<->SBV変換を行う
1. 変換したいSRTファイルまたはSBVファイルを読み込む
2. 出力したいファイル形式の出力ボタンを押す

```
※SBVファイルについて1行目がイントロ部で歌詞がない場合、空白行を削除することを推奨します。
```

## その他注意事項
- 本ツールが入力されたファイルを取得、保存することはありません。
- 本ツールの制作に生成AIを用いています。
- 他者の楽曲及び歌詞は著作権・原盤権によって保護されています。ファイルの取り扱いにはご注意ください。
